## Resumo

Um template com o eslint, prettier, webpack e workflow configurado como eu geralmente venho usado até o momento (02/02/2026), ou seja, projetos em node.js

## Para usar GitHub Pages:

1. **Se repo for público:** 
   - Habilite em Settings → Pages → Source: GitHub Actions

2. **Se repo for privado (plano gratuito):**
   - Use outro serviço (Netlify, Vercel, Cloudflare Pages)
   - Ou faça upgrade para GitHub Pro

3. **Alternativa:** Build local e deploy manual
